# **App Name**: GroupHub

## Core Features:

- User Accounts: User authentication and profile creation/management
- Group Management: Allow creation and management of user groups, specifying privacy settings for membership and content.
- Direct Messaging: Private messaging feature enabling one-on-one communication between group members.
- Message Board: Public message board for group-wide announcements and discussions.
- Events Tool: Simple tool to post and display organized group events.

## Style Guidelines:

- Primary color: Muted violet (#9B5DE5) for a sense of community and connection.
- Background color: Very light violet (#F2F0F7) to ensure comfortable readability.
- Accent color: Warm pink (#F15BB5) for highlights, calls to action, and interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) provides a modern and readable aesthetic.
- Simple, geometric icons to represent different functionalities within the app.
- Clean, card-based layout to organize content and improve user experience.
- Subtle transition animations between pages and elements to create a fluid user experience.
